Single sign-on (OpenID Connect)

Sign in with Authelia (or Keycloak, Entra ID, Google…): the sign-in page shows a button that sends users to the identity provider. Users are found by their single sign-on account, else linked by username or e-mail, else created. Provider groups can set the global role.

Provider
Its /.well-known/openid-configuration is read
Accounts and roles
Cars are then given on the Users page (or by a group below)
Untick to make single sign-on the only way in. If you get locked out, set "allow_local_login": true in config.json (or ALLOW_LOCAL_LOGIN=1) and restart.
