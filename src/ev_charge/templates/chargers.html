Chargers

The chargers of your group, whose sessions are reimbursed: home wall box, mobile charger… Picking one in a session makes it to be reimbursed and, when the charger uses the home tariff, prices it at the CREG tariff of its date. The reimbursing company (e.g. 50five, Enco e-Mobility) is the one that pays the sessions back; the reimbursement statement can be filtered on it.

Connection

EV Charge reads the charger (its cloud account, or the charger itself on your network) to follow the live session (a session is created when charging starts, ⏳ In progress while plugged in, ✓ Recorded once unplugged) and to import its charging history. The credentials are stored encrypted and checked now. Zaptec: official API, with the Zaptec Portal account; its history lists the exact sessions. Ohme: no official API, the connection uses the same unofficial API as the Ohme app and Home Assistant; its history is hourly. Easee: official cloud API, with the Easee app account; its history lists the exact sessions. go-e: official API, either on your local network (allow “local HTTP API v2” in the go-e app; this server must be on the same network) or through the go-e Cloud (serial number and Cloud API token from the app); no history. NRGkick (Gen2): its local JSON API only (enable it in the NRGkick app; same network); no history. Home Assistant: when the charger is on a smart plug, its power and energy sensors (long-lived access token from your HA profile); its history is hourly.

Charging history

Zaptec and Easee list their sessions (exact times); Ohme only gives an hourly history, from which sessions are rebuilt (consecutive hours with energy = one session, times rounded to the hour). Each one is compared with the sessions already recorded: new ones can be added (✓ Recorded), matching ones (same day, close kWh) can be linked to this charger.
